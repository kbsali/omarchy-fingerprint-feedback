# 0001. Record architecture decisions

Date: 2026-11-19

Status: accepted

## Context

Choices that are hard to reverse, or that would puzzle a newcomer, need a
written reason that outlives the conversation that made them.

## Decision

Record them as ADRs in `docs/adr/`, numbered `NNNN-kebab-title.md`, from
`0000-template.md`. An accepted ADR is never rewritten: a new one supersedes it.

## Consequences

`docs/adr/README.md` lists every ADR with its status.
